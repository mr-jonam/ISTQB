# CT-SEC — Security Tester

Affronta il security testing lungo il ciclo di vita: rischio, processi, revisione, tecniche, fattori umani e reporting responsabile.

## Per l'esame

- Verifica materiali e prerequisiti nella [pagina ufficiale CT-SEC](https://istqb.org/certifications/certified-tester-security-tester-ct-sec/).
- Collega minaccia, vulnerabilità, impatto, controllo e test.
- Distingui verifica di requisiti, vulnerability assessment e penetration testing.

## Domande di allenamento

1. Perché la severità tecnica non coincide sempre con il rischio di business?
2. Quali informazioni vanno protette in un security test report?

## Sul campo — threat-driven test plan

**Scenario:** portale con dati personali e ruoli. **Consegna:** asset map, abuse case, controlli e test autorizzati. **Criteri:** scope scritto, ambiente sicuro, nessun dato reale, disclosure responsabile. **Evidenza:** report sanitizzato con rischio residuo e remediation verificabile.
