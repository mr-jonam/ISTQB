# Defect report

- **Titolo:** comportamento + condizione + impatto.
- **Ambiente/versione:** build, device/browser, configurazione.
- **Precondizioni e dati:** minimi e anonimizzati.
- **Passi per riprodurre:** numerati e deterministici.
- **Risultato osservato:** fatto, non interpretazione.
- **Risultato atteso:** fonte dell'oracolo.
- **Riproducibilita:** frequenza e tentativi.
- **Impatto/severita:** utenti, dati, business, workaround.
- **Evidenze:** log essenziali, screenshot o trace senza segreti.
- **Note diagnostiche:** ipotesi esplicitamente marcate.
