# Test charter

- **Missione:** esplorare [area] per scoprire [rischio/informazione].
- **Scope:** incluso / escluso.
- **Durata:** timebox e partecipanti.
- **Dati e ambiente:** condizioni necessarie.
- **Oracoli:** come riconosciamo un problema.
- **Tour/euristiche:** approccio iniziale.
- **Rischi prioritari:** cosa puo compromettere valore o fiducia.
- **Note:** osservazioni, domande, test eseguiti.
- **Finding:** evidenza e impatto.
- **Debrief:** copertura, ostacoli, rischi residui, prossima sessione.
