# Foundation CTFL

Versione di riferimento: **CTFL v4.0.1**. Il CTFL costruisce linguaggio comune, tecniche di base e comprensione del test management. E il punto di partenza per i percorsi che richiedono Foundation.

## Le sei aree

| Area | Devi saper spiegare | Devi saper fare |
|---|---|---|
| Fondamenti | obiettivi, principi, testware e ruoli | distinguere test e debugging |
| SDLC | livelli, tipi e maintenance | adattare il testing al ciclo di vita |
| Static testing | review e feedback | condurre una review focalizzata |
| Analisi e design | black-box, white-box, experience-based, collaboration | derivare test e copertura |
| Gestione | piano, rischio, monitoraggio, difetti | prioritizzare e comunicare stato |
| Tool | supporto, benefici e rischi | scegliere un uso sensato dell'automazione |

## Criterio di completamento

Non basta riconoscere la risposta. Completa un mini-portfolio con:

- una tabella di decisione e relativi test;
- una partizione di equivalenza con valori limite;
- un report di difetto riproducibile;
- un registro dei rischi con priorita motivate;
- una mini strategia di test collegata a obiettivi e metriche.
