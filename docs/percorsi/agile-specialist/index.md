# Agile e Specialist

Le certificazioni Agile e Specialist rispondono a contesti diversi. Evita di scegliere dal titolo: confronta business outcome, prerequisiti, versione e lavoro che vuoi svolgere nei prossimi 12 mesi.

## Matrice di scelta

| Bisogno | Evidenza da cercare nel syllabus | Prova sul campo |
|---|---|---|
| integrare qualita nel delivery Agile | collaborazione, feedback, CI/CD | Definition of Done e quality gates |
| testare sistemi AI | caratteristiche, dati, bias, non-determinismo | evaluation set e failure taxonomy |
| security testing | minacce, vulnerabilita, tecniche | threat-informed test charter |
| performance | workload, misure, ambiente | modello di carico e baseline |
| usability/accessibility | utenti, contesto e qualita d'uso | protocollo di valutazione |
| mobile | piattaforme, connettivita, device | matrice device/rischi |
| acceptance testing | collaborazione e criteri | esempi eseguibili condivisi |

## Canvas di specializzazione

Compila una pagina:

- problema professionale da risolvere;
- modulo e versione scelta;
- tre learning outcome rilevanti;
- progetto laboratorio;
- esperto/reviewer;
- misura prima/dopo;
- artefatto pubblicabile senza dati sensibili.

!!! warning "Catalogo dinamico"
    Alcuni moduli vengono introdotti, aggiornati o ritirati. Consulta il [catalogo ufficiale](https://www.istqb.org/certifications/) e la pagina del singolo modulo prima di iniziare.
