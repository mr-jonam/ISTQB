## Categorie di tool

| Bisogno | Esempi di categoria | Criterio di scelta |
|---|---|---|
| mappe e note | Markdown, diagrammi, knowledge base | esportabilita e ricerca |
| flashcard | spaced repetition | controllo dei dati e portabilita |
| test design | model/table editor | tracciabilita e collaborazione |
| API | client e runner | scriptabilita, secret handling |
| UI | browser automation | affidabilita, debug, accessibilita |
| performance | load generator e telemetry | modello realistico e osservabilita |
| security | scanner e review manuale | spiegabilita e gestione falsi positivi |
| quality intelligence | dashboard e query | decisioni, non vanity metrics |

## Prova prima di adottare

Valuta su un caso reale ma non sensibile: tempo al primo feedback, stabilita, manutenzione, integrazione CI, accessibilita, costo totale, lock-in, sicurezza dei dati e facilita di dismissione.
